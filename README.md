# Rokuzen

Full-stack web application developed as the Integrative Project for the 2nd semester of Computer Science at Instituto Mauá de Tecnologia.

## 🧩 About

Rokuzen is a web platform built with a JavaScript backend handling core business logic and a frontend built with HTML and CSS. I was responsible for the majority of the backend development, including application features and data flow, alongside contributions to the frontend integration.

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Backend | JavaScript (Node.js) |
| Frontend | HTML, CSS |
| Version Control | Git / GitHub |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/pleomoreno/projeto-rokuzen.git
cd projeto-rokuzen

# Install dependencies
npm install

# Run the application
npm start
```
